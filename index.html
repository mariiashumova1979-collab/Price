Как читать таблицу и формат CSV

Δ к бл. — насколько введённый Freedom24 % отличается от ближайшего подхода. Зелёный (|Δ| ≤ 0.10 п.п.) — Freedom24 чисто совпадает с этим подходом. Жёлтый/красный — число не ложится ни на один подход, значит используется своя логика.

ближе к — к какому из двух подходов введённое число ближе.

Наведите на тикер — во всплывающей подсказке опорные цены обоих подходов.

CSV с ценами закрытия — заголовок и строки. Разделитель «,» или «;» определяется автоматически (для «;» десятичная запятая, как в Excel-RU). Распознаются колонки:

ticker, n26, n28, d31, j02, now, f24_6m, f24_ytd

где n26 = закрытие 26.11.2025, n28 = 28.11.2025, d31 = 31.12.2025, j02 = 02.01.2026, now = текущая цена. Колонки f24_6m / f24_ytd необязательны — если заполнены, подставятся в Freedom24 %. После загрузки в таблице остаются только тикеры из CSV (в порядке файла) — позиции, которых нет в файле, убираются. Кнопка «Скачать шаблон CSV» выгружает текущие данные в этом формате — отредактируйте и залейте обратно.

Общий доступ для всех. Цены и значения Freedom24, которые вы ввели или загрузили, по умолчанию хранятся только в вашем браузере. Чтобы их видел любой пользователь, нажмите «Сохранить общий index.html» — скачается самодостаточный файл с этими данными, уже встроенными как значения по умолчанию. Задеплойте его на Vercel/Netlify вместо текущего — и все, кто откроет ссылку, увидят ваши данные. Локальные правки каждого пользователя при этом накладываются поверх и не затрагивают общий файл.

Цены по умолчанию — иллюстративные, отражают реальные уровни мая 2026. Для точных расчётов загрузите CSV с фактическими закрытиями из вашего фида. Введённые вручную значения Freedom24 сохраняются в браузере (для каждого периода отдельно) и переживают перезагрузку при открытии файла как страницы.
